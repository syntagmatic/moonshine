# d3 group review: d3-power-tools (37 articles + index, ~81k words, all added 2026-04-10)

## What the series is
A companion to an external Claude skill pack called "d3-power-tools". Each page = one SKILL.md
explained: subtitle, a bolded "key insight" line, one or more figures, a few sections, then a
templated "When This Skill Hurts" section (33 of 37 pages) about how *LLMs* misapply the skill.
Pages repeatedly cite "the skill file", "the d3-power-tools brushing skill", `evals/run-evals.py`,
SKILL.md triage, etc. Five pages (calibrate-tool, sharpen-tool, visual-critic, stress-test in part,
jig-template) are about authoring/evaluating AI skills, not about visualization for a reader.
Content is standard vis-textbook material (rainbow bad, 8% CVD, box plot hides bimodality, Tissot,
lie factor, Miller/Cowan, small multiples, sparklines, semantic vs geometric zoom) plus D3 API
tours already covered better by d3js.org and the Observable gallery. Only 4 pages show code blocks.

## Verified errors (source checked)
- edge-bundling.html:285, 491, 586: claims "beta 0 = maximum bundling (tension 1), beta 1 = straight
  lines" and sets `beta = 1 - tension`. This is backwards. In D3 v7 `curveBundle.beta(0)` is a straight
  line and `beta(1)` follows the control points. So the "Bundled (tension 0.85)" panel actually renders
  beta 0.15 (nearly straight), and the "useful range 0.5-0.85" advice is inverted. The article's
  central figure and argument are wrong.
- d3-idioms.html reusable-chart code: `chart.width = _ => arguments.length ? ... : width`. Arrow
  functions have no own `arguments`; this reads barChart()'s (length 0), so every setter is a getter.
  `barChart().color("#2563eb")` returns a string and `.call(...)` throws. The one showcase snippet on
  the "idioms" page is broken. (Also calls enter/merge/exit "the D3 v3 way"; merge is v4.)
- stress-test.html:334/380: says without `.interrupt()` transitions "queue up" and "pile up". In D3 v7
  a new same-name transition interrupts the active one automatically; the page itself says so at :398.
  Figure 2's "without interrupt" mode behaves identically and only prints a "Conflict #n" label
  (:808-817). The "Transition Queue" health counter is its own bookkeeping (++ per update, -- per bar
  'end'), not a measurement.
- calibrate-tool.html:507-510, 794: "Simulated calibration run" scores are Math.random() ranges
  hardcoded so "with skill" wins; Figure 2 noise is synthetic. Fabricated evidence for the claim.
- scales.html: log-scale *bars* drawn from an arbitrary baseline (0.7*min), the very distortion the
  encoding-integrity page warns about; prose says Iceland ~10x smaller than Estonia (data: 3.6x) and
  Estonia ~10x smaller than Sweden (7.7x).
- cognitive-load.html:378/585: labels the 4-chunk line "Miller's threshold" (Miller is 7+-2; 4 is Cowan,
  which the page itself explains two paragraphs later). Meter just counts toggled layers.
- color: "collapses red-green distinctions entirely" for 8% of males overstates (most are anomalous
  trichromats). Minor.
Figures that do compute real things: distributions (real KDE/quantiles), cartography (d3.geoCircle
Tissot), data-gathering (d3.group/rollup/bin), encoding-integrity, force, webgl (real shaders),
shape-morphing (resampling + projection interpolation), brushing.

## Series paragraph
This is reference documentation for an AI skill pack, reformatted as 37 same-shaped pages. It fails
Fit by construction: the implied reader is someone writing prompts for Claude to generate D3 (every
page ends with how LLMs misuse the skill), not a Distill reader. Substance is textbook vis practice
and D3 API tours that d3js.org, Observable, Munzner and Tufte already cover, with no page advancing a
non-obvious argument. Craft is uniformly templated (subtitle, "key insight", figure, "When This Skill
Hurts"). Figures are mostly real D3, but three pages have fabricated or non-functional demos and two
contain D3 errors that would mislead exactly the reader a tutorial targets (curveBundle beta
inverted; broken reusable-chart getter-setters). Fixing it would mean rewriting it as a different
series. Verdict: CUT the whole series (37/37 articles + index, ~81k words), remove the homepage entry.
If anything is salvaged, the semantic-zoom (navigation) and projection-morph (shape-morphing) figures
are the only ones that could seed an essay elsewhere.
