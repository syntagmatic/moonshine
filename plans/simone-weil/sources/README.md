# Simone Weil Source Packet

This folder collects source anchors for the Simone Weil series. It is a working packet for building the explainers, not a public quotation anthology.

## Files

- `source-map.md` - edition and web anchors by work, plus reliability notes.
- `critical-quotes.md` - short quote fragments, paraphrase, and explainer use.
- `vocabulary-connections.md` - source questions suggested by the vocabulary notes.

## Quotation Policy

Use short quotations on the pages. Prefer close paraphrase, diagrams, and source-aware captions. Before publishing any exact wording, verify it against the edition used for the page.

The English translations of Weil are often copyrighted and vary by edition. The quote fragments here are intentionally brief. Treat them as anchors for finding the passage, not as a substitute for checking the book.

## Source Tiers

- **Tier A:** Project editions or scans owned/checked by the author.
- **Tier B:** Reputable excerpts with source context, such as Wikiquote entries with page references or primary-text excerpts.
- **Tier C:** Quote aggregators, secondary articles, and search snippets. Useful for locating passages, not enough for final wording.

## Implementation Use

Each explainer should include one or two source-aware touches:

- a brief exact fragment where the wording is crucial;
- a caption that names the source cluster;
- a caution when the quote comes from a posthumous collection;
- a connection back to the concept graph: necessity, attention, the impersonal, metaxu, rootedness, or force.
