# 14 — E8 as an Error-Correcting Code

## Pitch

Sphere packing and error correction are the same optimization problem dressed in different clothes. A good error-correcting code packs codewords as far apart as possible in the Hamming metric so that noise can be corrected; a good lattice packing places sphere centers as far apart as possible in the Euclidean metric so that balls don't overlap. This explainer makes the equivalence concrete by walking through one specific example: the extended Hamming [8, 4, 4] binary code, processed through Construction A, becomes the E8 lattice. The reader gets a third description of E8 — now seen as roots, as D₈⁺ cosets, and as a code — and understands that those three descriptions are genuinely different lenses onto the same object. More importantly, they leave with the realization that *every claim this series has made about E8's kissing number and packing density is simultaneously a claim about an error-correcting code's decoding performance.*

## Key formulas / constructions

- **Construction A:** `Λ(C) = {x ∈ ℤⁿ : (x mod 2) ∈ C}`, where `C ⊆ 𝔽₂ⁿ` is a binary linear code. The output is a lattice; if `C` has minimum distance `d`, then `Λ(C)` has minimum squared length at most `min(d, 4)` (the 4 coming from the integer lattice's own minimum).
- **Extended Hamming [8, 4, 4]:** length 8, dimension 4, minimum distance 4, self-dual. 16 codewords. Generated by the `4 × 8` matrix whose rows are the 4 fundamental codewords (standard Hamming generator matrix extended with a parity bit).
- **E₈ via Hamming:** `E₈ ≅ (1/√2) · Λ(extended Hamming [8, 4, 4])`. After the scaling, the minimum squared length becomes 2, matching our earlier descriptions.
- **Weight enumerator ↔ theta series:** for a Construction A lattice, the theta series is computable from the weight enumerator of the code via a clean substitution; for the extended Hamming code, this substitution recovers the first few terms of the E8 theta series (1, 240, 2160, ...).
- **Self-duality:** the extended Hamming code is self-dual as a code, which forces the resulting lattice to be unimodular.
