Moonshine

Interactive explanations that turn technical complexity into explorable understanding.

AI tools generate complexity faster than people can consume it. Moonshine bridges that gap: turning dense technical concepts into interactive articles where readers can drag, brush, toggle, and build intuition at their own pace. Inspired by Distill.pub, each explanation is a self-contained HTML file built with D3 and vanilla JS.

The Approach

A complex waveform is hard to interpret whole. Decompose it into sine waves and you can toggle components to see how they combine. The same principle applies to any technical concept: find the parts, make them interactive, and let the reader build understanding from the pieces.

Using Moonshine

Moonshine is a skill for AI coding assistants. It guides a structured conversation: story discovery, interaction design, scaffolding, and iterative building. It asks questions about what you're explaining and who the audience is before writing any code.

# Install the skill
/plugin marketplace add enjalot/moonshine
/plugin install moonshine@moonshine-marketplace

# Start a new explanation
/shine how gradient descent finds minima

Or install manually: git clone https://github.com/enjalot/moonshine.git and copy plugins/moonshine to ~/.claude/skills/moonshine.

Distill.pub articulated why distillation matters. Mike Bostock created D3.js and showed how visualization and narrative work together. Bret Victor imagined explorable explanations. Nicky Case, Bartosz Ciechanowski, and The Pudding proved the format works across subjects.
