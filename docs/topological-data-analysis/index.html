The Shape of Data

Data has shape, and the shape matters. Three interactive explainers on topological data analysis: from a point cloud to a simplicial complex, from the combinatorics to the Mapper graph.

Topological data analysis starts from a simple observation: a point cloud sampled from a circle looks different from one sampled from three clusters, not because the individual points differ, but because the shape is different. TDA makes "shape" precise using the language of algebraic topology: simplicial complexes, homology groups, Betti numbers, and the Mapper algorithm that turns high-dimensional point clouds into readable graphs.
