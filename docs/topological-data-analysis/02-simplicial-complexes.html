The Core Concept

The Rips complex built shapes based on exact distances between coordinates. But topological features like components, loops, and voids don't actually care about coordinates. They only care about connections.

This purely combinatorial structure is called an abstract simplicial complex. It is simply a list of subsets: a list of vertices, a list of edges, a list of triangles, and so on. The only rule is closure: if a triangle is in the complex, all of its edges and vertices must be in the complex too. A solid triangle cannot exist without its boundary.

The f-vector and Euler characteristic: The f-vector counts simplices by dimension (vertices, edges, triangles). The Euler characteristic (χ) is the alternating sum of these counts. It is a powerful topological invariant: a single integer that depends only on the topology, not the geometry.

The Hasse diagram: Also called the face lattice, this diagram arranges all simplices in layers by dimension, connecting each simplex to its immediate faces. It encodes the full combinatorial structure without any geometry.

Concept Summary

  • Forget the coordinates: An abstract simplicial complex is just a list of connections. Once the connections are defined, the geometric coordinates no longer matter for finding loops and voids.
  • Count the pieces: The f-vector tracks exactly how many vertices, edges, and triangles exist, while the Euler characteristic combines these counts into a single powerful invariant number.
  • Draw the hierarchy: The Hasse diagram is the true map of a shape, showing exactly how lower-dimensional pieces build up into higher-dimensional ones.
