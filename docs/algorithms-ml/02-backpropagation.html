Backpropagation

A neural network learns by following blame backward through its connections.

A neural network starts with random weights and produces nonsense. Training adjusts the weights with gradient descent from the previous article, which needs the gradient of the loss with respect to every one of them. Backpropagation computes those gradients by tracing the error at the output backward through every connection, assigning each weight a share of the blame.

Information Flows Forward

Here is a small network: two inputs, three hidden nodes, one output. Each node computes a weighted sum of its inputs, then squashes the result through a sigmoid function to produce an activation between 0 and 1. Positive weights pass the signal along and negative weights flip it.

The Forward Pass, Step by Step

Figure 2 slows the forward pass down, from the inputs to the point where the prediction meets the target.

Step 1

Input values enter the network from outside.

Step 2

Each hidden node computes a weighted sum, with every incoming connection multiplying its input by its weight. The stacked bars show each contribution: blue bars push the sum up and red bars pull it down.

Step 3

The sigmoid squashes each weighted sum into the range (0, 1). Sums far from zero land near 0 or 1; sums near zero land around 0.5.

Step 4

The output node repeats the same process: weighted sum of hidden activations, then sigmoid. This gives the network's prediction.

Step 5

The loss measures the gap between prediction and target, highlighted between the two bars. Squared error penalizes large mistakes more than small ones.

Figure 2. The forward pass, one step at a time. Scroll through the steps.

Measuring How Wrong You Are

The loss is a single number for the network's mistake. It is zero when the prediction matches the target and grows as they diverge.

The loss gives the total error but says nothing about which weights caused it. The backward pass works that out.

The Backward Pass

For each weight, the backward pass measures how much the loss would change if that weight were slightly different. That sensitivity is the gradient.

The chain rule makes this tractable. At each node, the incoming gradient gets multiplied by the local gradient, which is the derivative of whatever that node computed. For a sigmoid node, the local gradient is the slope of the sigmoid curve at the current operating point. Gradients compose by multiplication as they flow backward through the network.

Figure 3. The backward pass. Red pulses carry gradients from the output back toward the inputs, and edge labels show each weight's gradient.

Each node only needs its own local derivative. Multiply that by the gradient arriving from downstream and you have the gradient to pass upstream. No node needs a global view.

Weight Updates

Once every weight has a gradient, each one shifts against it, in proportion to its size. A weight with a large gradient has a big effect on the loss and gets a big adjustment; a weight with a small gradient barely moves. The learning rate η sets the step size, with the same trade-offs as in gradient descent.

Why Deep Sigmoid Networks Stall

Figure 3 multiplied the gradient by the sigmoid's slope at every node on the way back. That slope is σ(z)(1−σ(z)). It is 0.25 at z = 0, its largest value, and smaller everywhere else. In a network with many layers, the gradient reaching layer k has passed through every layer above it, picking up one factor of weights times slopes per layer. With weights of ordinary size, each factor is around a quarter, and the factors multiply: ten layers at a quarter each is about one millionth.

Figure 5 measures this. It builds a stack of 16-unit layers with random weights, runs a batch of 64 random inputs forward, computes a squared-error loss against random targets, and backpropagates. The plot shows the typical size of the loss gradient for each layer's weights, on a log scale.

Figure 5. Root-mean-square gradient of the loss with respect to each layer's weights, from layer 1 (next to the input) to the last hidden layer, for one batch. Weights are drawn from a normal distribution with standard deviation scale/√16. The gray line is the other activation function with the same settings.

With sigmoid units at weight scale 1, the gradient falls by roughly a factor of four per layer going back, as the slope argument predicts, and the first layer's gradient is several orders of magnitude smaller than the last layer's. Gradient descent then changes the early layers very slowly. Raising the weight scale increases the multiplier from the weights, but it also pushes the weighted sums away from zero, onto the flat parts of the sigmoid, and the average slope in the readout drops. Near scale 8 the two effects roughly cancel and the gradient stops shrinking from layer to layer, but by then most units sit close to 0 or 1, where small changes in their input barely change their output. ReLU has slope exactly 1 wherever a unit is active, and with the weight scale near √2 (the scaling proposed by He et al., 2015) its gradients stay at a similar size from the last layer to the first. This is one of the reasons deep networks moved from sigmoid to ReLU hidden units.
