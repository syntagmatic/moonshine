Backpropagation

A neural network learns by sending its error backward through its connections.

A neural network starts with random weights, so its outputs have nothing to do with the task. Training adjusts the weights with gradient descent from the previous article, which needs the gradient of the loss with respect to every one of them. Backpropagation computes those gradients by tracing the error at the output backward through every connection, working out how sensitive the loss is to each weight.

Information Flows Forward

Take a small network: two inputs, three hidden nodes, one output. Each node computes a weighted sum of its inputs, then squashes the result through a sigmoid function to produce an activation between 0 and 1. Positive weights pass the signal along and negative weights flip it.

Measuring How Wrong You Are

The loss is a single number for the network's mistake. It is zero when the prediction matches the target and grows as they diverge.

The loss gives the total error but says nothing about which weights caused it. The backward pass works that out.

The Backward Pass

For each weight, the backward pass measures how much the loss would change if that weight were slightly different. That sensitivity is the gradient.

The chain rule makes this tractable. At each node, the incoming gradient gets multiplied by the local gradient, which is the derivative of whatever that node computed. For a sigmoid node, the local gradient is the slope of the sigmoid curve at the current operating point. Gradients compose by multiplication as they flow backward through the network.

Figure 2. The backward pass, at the inputs 0.60 and 0.40 with target 0.85. Red pulses carry gradients from the output back toward the inputs. Edge labels show each weight's gradient dL/dw; the label above each hidden node is dL/dz, the gradient at that node's weighted sum.

Each node only needs its own local derivative. Multiply that by the gradient arriving from downstream and you have the gradient to pass upstream. No node needs a global view.

Weight Updates

Once every weight has a gradient, each one shifts against it, in proportion to its size. A weight with a large gradient has a big effect on the loss and gets a big adjustment; a weight with a small gradient barely moves. The learning rate η sets the step size, with the same trade-offs as in gradient descent.

Why Deep Sigmoid Networks Stall

Figure 2 multiplied the gradient by the sigmoid's slope at every node on the way back. That slope is σ(z)(1−σ(z)). It is 0.25 at z = 0, its largest value, and smaller everywhere else. In a network with many layers, the gradient reaching layer k has passed through every layer above it, picking up one factor of weights times slopes per layer. With weights of ordinary size, each factor is around a quarter, and the factors multiply: ten layers at a quarter each is about one millionth.

Figure 4 measures this. With sigmoid units at weight scale 1, the gradient falls by roughly a factor of four or five per layer going back, as the slope argument predicts, and the first layer's gradient is several orders of magnitude smaller than the last layer's. Gradient descent then changes the early layers very slowly. Raising the weight scale increases the multiplier from the weights, but it also pushes the weighted sums away from zero, onto the flat parts of the sigmoid, and the average slope in the readout drops. Near scale 8 the two effects come close to cancelling: the shrink falls to about 1.3 per layer, and for some draws of the weights (try New random weights) the gradient does not shrink at all. That is not a cure, because by then about 60% of the units sit within 0.05 of 0 or 1, where small changes in their input barely change their output.

ReLU has slope exactly 1 wherever a unit is active, and its profile stays roughly flat at every weight scale on the slider. Without biases, multiplying every weight by a constant scales each layer's signal by that constant, so the scale cannot change how the gradient varies from layer to layer. What it changes is the overall size, which the readout prints for layer 1. Near scale √2, the scaling proposed by He et al., 2015, signals keep roughly the same size from layer to layer, and going from 2 layers to 20 shrinks layer 1's gradient only about fivefold. At scale 1 the same change shrinks it about two thousandfold, and at scale 2 it grows about ten thousandfold. This is one of the reasons deep networks moved from sigmoid to ReLU hidden units.
