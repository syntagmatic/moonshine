Roots and the Root Space Decomposition

Part 3 of 15. Simultaneous diagonalisation of the Cartan subalgebra breaks 𝔤 into the Cartan plus a finite family of one-dimensional root spaces. The non-zero eigenvalues form the root system, a finite set of linear functionals that will carry the classification.

Explainer 2 set up the machinery: a Cartan subalgebra 𝔥 is a maximal abelian collection of semisimple elements, and the linear-algebra fact about commuting diagonalisable operators says that {adh : h ∈ 𝔥} can be simultaneously diagonalised on 𝔤. We even wrote the statement of the resulting decomposition. This explainer unpacks it.

We describe what the joint eigenspaces look like, verify the decomposition for sl3 by hand, and then list the structural facts about root spaces that the rest of the series depends on: that the non-zero α's come in pairs (α, −α), that brackets of root spaces land in other root spaces in a predictable way, and, the most useful single fact, that each non-zero 𝔤α is strictly one-dimensional. The last fact is what turns the classification problem from "classify a Lie algebra" to "classify a finite set of vectors in Euclidean space."

The decomposition theorem

Fix a semisimple Lie algebra 𝔤 over ℂ and a Cartan subalgebra 𝔥 ⊂ 𝔤. For any linear functional α ∈ 𝔥* (that is, any linear map 𝔥 → ℂ), define

Each 𝔤α is a subspace of 𝔤, the joint eigenspace of the whole family of operators {adh : h ∈ 𝔥}, with joint eigenvalue α. For most α the subspace 𝔤α is zero; only finitely many α give non-trivial eigenspaces, and those α are called the roots of 𝔤 with respect to 𝔥.

The root system is the set

of all non-zero functionals whose eigenspaces are non-empty. (We exclude α = 0 because 𝔤0 is a different beast, it contains the Cartan itself, and we will see that 𝔤0 = 𝔥 exactly.) Δ is finite: it has size equal to the dimension of 𝔤 minus the rank, split evenly between "positive" and "negative" once we pick an ordering (explainer 7).

As a direct sum of vector spaces. Every element of 𝔤 can be written uniquely as a Cartan element plus one contribution from each root space, and the bracket structure of 𝔤 is visible in how these components interact. The decomposition has four facts that matter for the classification, all of which we state as black boxes for now and return to in later explainers.

The four facts.

(1) 𝔤0 = 𝔥. The zero eigenspace equals the Cartan subalgebra itself. Nothing else has joint eigenvalue zero.

(2) Root spaces come in pairs. If α ∈ Δ, then −α ∈ Δ. The roots of a semisimple Lie algebra are symmetric about the origin in 𝔥*.

(3) Each root space is one-dimensional. For every α ∈ Δ, dim 𝔤α = 1. In a simple Lie algebra, each root α identifies exactly one direction in 𝔤, up to scalar.

(4) Brackets are additive on roots. If x ∈ 𝔤α and y ∈ 𝔤β, then [x, y] ∈ 𝔤α+β. In particular, [𝔤α, 𝔤β] is zero unless α + β is zero or a root.

Facts (1), (2), and (4) follow from general arguments about joint eigenspaces, the Jacobi identity plus a careful accounting of how adh interacts with brackets. Fact (3) is the deep one: it holds for semisimple Lie algebras specifically, and its proof uses the embedded sl2 triples we will meet in explainer 5. For now accept it as given. It is the single most restrictive piece of structure we will have to work with, and it is what makes the classification possible at all.

sl3: the first concrete instance

We can verify every one of the four facts by direct computation in sl3(ℂ). Write its Cartan as 𝔥 = {diag(h1, h2, h3) : h1 + h2 + h3 = 0}, a 2-dimensional subspace. The other six dimensions of sl3 are spanned by the six matrix units Eij, the 3×3 matrix with 1 in position (i, j) and 0 elsewhere, for i ≠ j.

Why one-dimensionality matters

Of the four facts above, the one worth pausing on is fact (3): every non-zero root space in a semisimple Lie algebra is one-dimensional. This might look like a small technical claim, but it is the assertion that turns an infinite-dimensional classification problem into a finite combinatorial one.

Here is the argument, abstracted. A semisimple Lie algebra 𝔤 of rank r is some number of dimensions, call it d. The Cartan subalgebra takes up r of those dimensions. The remaining d − r dimensions are distributed over the root spaces 𝔤α. If each 𝔤α had arbitrary dimension, we would need to record the dimension of each root space as part of the data of 𝔤, and the classification would be much more complicated. But one-dimensionality says: there is exactly one root per missing dimension, so |Δ| = d − r. Once we know the root system Δ as an abstract finite set in 𝔥*, we know everything about 𝔤 beyond the Cartan itself, up to isomorphism.

This is the moment where "classify semisimple Lie algebras" becomes "classify finite configurations of vectors". The rest of Act I sets up what structure a root system must have, and Act II proves the sharp classification of those structures. But the move from algebra to geometry happens right here, at fact (3).

Rank counting. For sln+1: dimension n(n+2), rank n, so |Δ| = n(n+2) − n = n(n+1). That's the root count of An. For so(2n+1): dimension n(2n+1), rank n, so |Δ| = 2n². For E8: dimension 248, rank 8, so |Δ| = 240. Every one of the nine families in the classification satisfies this arithmetic, and the arithmetic works because root spaces are one-dimensional.

Bracket additivity and the root string

Fact (4), bracket additivity, deserves one more look because it is the workhorse of every structural calculation we will do. Stated more explicitly:

If x ∈ 𝔤α and y ∈ 𝔤β, then [x, y] ∈ 𝔤α+β. Because 𝔤γ is zero unless γ is a root or zero, this tells us: the bracket [x, y] is zero unless α + β is zero, is a root, or equals the zero functional (in which case [x, y] lies in 𝔥 itself). In a simple Lie algebra, one can show further that [𝔤α, 𝔤β] = 𝔤α+β whenever α + β is a root, there is no hidden cancellation. So the bracket is not just limited to landing in 𝔤α+β, it actually surjects onto it whenever the target is a root space.

A consequence: for any root α and any β ∈ Δ, the sequence of roots

— obtained by walking from β in the direction of α, is an unbroken string, meaning it is a consecutive run of integers p ≤ k ≤ q for some integers p ≤ 0 ≤ q with no gaps. This is the α-string through β, and its length p + q + 1 will turn out to be one of the integer constraints that the classification extracts from the root system. Explainer 5 proves that root strings have at most four elements, which in turn forces the famous crystallographic restriction on root-system angles.

Root space decomposition for the classical families

The sl3 example generalises to every classical family in essentially the same way. In each case, the Cartan is a specific space of diagonal (or block-diagonal) matrices, and the root spaces are spanned by specific off-diagonal matrix units. Here is the table to anchor the later explainers:

Type Lie algebra Cartan 𝔥 Roots |Δ|
An sln+1(ℂ) diagonal, trace 0 εi − εj, i ≠ j n(n+1)
Bn so(2n+1, ℂ) diagonal, n entries ±εi ± εj, ±εi 2n²
Cn sp(2n, ℂ) diagonal, n entries ±εi ± εj, ±2εi 2n²
Dn so(2n, ℂ) diagonal, n entries ±εi ± εj 2n(n−1)

The exceptional algebras G2, F4, E6, E7, E8 do not have such a clean matrix description, their root systems require the combinatorial machinery of Dynkin diagrams and Cartan matrices from Act II, which is where they will be constructed. For now the table tells the classical half of the story: four infinite families indexed by rank, with a uniform root-space recipe, and that recipe will underlie the entire classification proof in Act II.

What we take with us

  • Root space decomposition. 𝔤 = 𝔥 ⊕ ⊕α ∈ Δ 𝔤α, where 𝔥 is the Cartan subalgebra and each 𝔤α is the joint eigenspace of the ad-action of 𝔥 with joint eigenvalue α ∈ 𝔥*.
  • Roots. The non-zero α ∈ 𝔥* for which 𝔤α ≠ 0. The set Δ of all roots is finite, symmetric about the origin (α ∈ Δ ⇒ −α ∈ Δ), and has size dim 𝔤 − rank 𝔤.
  • One-dimensionality. For semisimple 𝔤, every root space is one-dimensional. This is the key structural fact that turns the classification from "classify Lie algebras" to "classify finite configurations of vectors."
  • Bracket additivity. [𝔤α, 𝔤β] ⊆ 𝔤α+β, with equality whenever α + β is itself a root. This is the bookkeeping rule for how root spaces interact under the bracket.
  • sl3 as anchor. Six roots, one per ordered pair (i, j) with i ≠ j, sitting at the vertices of a regular hexagon in the 2-dimensional 𝔥*. This is the A2 root system, and it is the smallest example worth staring at.

The next explainer takes the final step from 𝔥* as an abstract dual space to a genuine Euclidean geometry on the roots. The Cartan–Killing form equips 𝔥 with a bilinear form; restricting and transporting it to 𝔥* turns Δ into a finite set of vectors in a real inner-product space. Once we have that inner product, every subsequent move in the classification is a Euclidean geometry calculation.
