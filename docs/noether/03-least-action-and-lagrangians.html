Least Action and Lagrangians

Part 3 of 15. A physical system is a single function, and its path through the world is the one that makes an integral of that function stationary.

Talking about symmetries of a physical system requires knowing what a physical system is. The answer modern physics starts from, and the answer Noether's theorem will be stated in, is a Lagrangian. A Lagrangian is a single function of position, velocity, and time; the integral of this function along a path is a number called the action; and the path the system actually follows is the one that makes this number stationary under small variations.

Variational problems before Lagrangian mechanics

The idea predates Lagrangian mechanics by a hundred and forty years. In June 1696, Johann Bernoulli posed the brachistochrone problem in the Acta Eruditorum: given two fixed points at different heights, which curve makes a bead, released from rest, slide down from one to the other under gravity in the shortest time? The curve is not the straight line. It is a cycloid, a curve traced by a point on a rolling wheel. Bernoulli, Leibniz, l'Hôpital, Jakob Bernoulli, and (famously, anonymously) Isaac Newton all produced solutions within months.

The Euler-Lagrange equation is not a guess or an axiom. It is the inevitable consequence of asking "what path makes the action stationary for every small variation?" Every assumption in that question is visible (the Lagrangian, the fixed endpoints, the smoothness) and every one is used. Noether's theorem in the next two explainers adds one more assumption: a continuous symmetry of the Lagrangian. Out drops a conservation law.

Concept Summary

  • A physical system is encoded in a Lagrangian .
  • The action is a number attached to each path.
  • The actual physical path is a stationary point of the action (Hamilton's principle).
  • Stationarity is equivalent to the Euler-Lagrange equation, which is the differential equation the path satisfies.
