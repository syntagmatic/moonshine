Causal Trees

Chapter 6 of 8. Every tree so far has asked "what will happen?" Causal trees ask a subtly different question: "what would change if I intervened?" That shift forces the algorithm to change, in a way that also forces it to split its data in half.

An online store sends a 20%-off promo to customers a model flags as likely buyers. Did the code work?

The model finds high-probability buyers, but those include customers who would have bought anyway and customers who would never buy. The group that matters — the persuadables, whose purchase depends on the code — is different.

Why standard trees can't answer this

A predictive tree finds splits that make each leaf's outcome homogeneous. What's needed instead are splits that separate people with different treatment responses. For any one customer, only one of "with code" or "without code" is observable, so the tree can't train directly on individual-level treatment effects.

The causal split criterion

Athey–Imbens 2016: instead of maximizing outcome purity, find splits where the two children have different average treatment effects.

For each candidate split, estimate uplift in each child as (treated mean) − (control mean). A good split separates a high-uplift subpopulation from a low-uplift one — say, +25% vs. +2%.

A predictive tree asks "who has high Y?" A causal tree asks "who has high Y-treated − Y-control?"

The double-dipping problem

Using the same data to pick the split and to estimate the uplift inside each leaf inflates the estimate: the split-finder was biased toward splits that happen to show high uplift on this sample. The more splits tried, the bigger the inflation.

This breaks confidence intervals. Standard-error calculations assume the tree structure was chosen independently of the data, which it wasn't.

Honest estimation

Athey and Imbens' fix: split the training data in half.

  • Use the first half to grow the tree: pick splits, decide the structure. Never look at the second half during this phase.
  • Use the second half to estimate the uplift in each leaf: for each leaf built from the first half, drop the second-half rows in and compute the average treatment effect. Never touch the structure.

Because the halves never interact, leaf-level estimates are honest. Standard confidence intervals work.

The cost is half your data. Causal forests use hundreds of trees so the splits across the ensemble recover the lost statistical power.

Figure 2. Honest estimation in action. The training half grows the tree and finds the persuadable region. The evaluation half drops fresh customers into the same region and computes a fresh uplift estimate — one that has not seen any of the splits being tested. At small N both estimates are noisy; as N grows, the honest estimate converges to the true effect while the naive estimate stays slightly inflated.

Caveats

Causal trees only work with randomized treatment assignment. If treatment was assigned by feature (salespeople gave discounts to interested-looking people), the "treatment effect" is confounded by selection, and the tree estimates something that isn't a causal effect.

A/B tests randomize by design. Observational data needs instrumental variables, propensity scores, or doubly robust estimation — outside this series.

The payoff

On randomized data, causal trees answer where the treatment works: where the promo code causes a purchase that wouldn't have happened, where the retention campaign changes behavior, where the drug actually helps.

The shift is from prediction to intervention: from "high-probability buyers" to "persuadables," from "predict outcomes" to "decide who benefits."

Takeaways

  • Predictive trees minimise Var(Y | leaf). Causal trees maximise Var(τ | leaf), where τ is the treatment effect. The split changes; the algorithm stays recognisable.
  • You never observe τ. For any single row, either you have Y-under-treatment or Y-under-control, not both. Causal trees find the split by comparing the two groups' averages in each candidate child.
  • Honest estimation splits the data in half. First half grows the structure, second half estimates the magnitudes. Statistical validity restored.
  • Requires randomised data. A/B tests work; observational data needs extra care to control confounding.
  • Different deliverable. Standard trees tell you what will happen; causal trees tell you where you can change what happens.
