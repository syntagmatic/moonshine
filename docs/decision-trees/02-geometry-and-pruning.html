Geometry and Pruning

Chapter 2 of 6. What axis-aligned splits buy, what they cost, and how to cut a grown tree back.

Each split tests one feature against a threshold, so in the plane it is a vertical or horizontal line and each leaf is a rectangle.

Why rescaling a feature changes nothing

A split only asks which side of a threshold a value falls on, so the tree sees the order of the values and nothing else. A strictly increasing transform keeps that order.

Nearest neighbours measure distance, so someone has to choose the scale. A tree never asks.

What a diagonal costs

The cost shows when the true boundary is diagonal: the tree can only build a staircase, and every step needs data to place.

What an oblique split has to search

An oblique split cuts along any direction. CART (1984) already offered these linear-combination splits, and OC1 (1994) searched for them by randomized hill climbing.

Best cut across this direction
Gini gain of the best cut, by direction

Figure 3. 80 seeded synthetic points in one node, two Gaussian clouds offset along a 40° diagonal. For each direction every cut between neighbouring projections is scored by Gini gain, and the curve keeps the best. A standard tree tries only the two axis directions. Drag along the curve.

Practical methods search this continuum of directions heuristically, and an oblique cut loses rank invariance: take the log of x and the best cut changes. For tabular data the staircase usually wins, and the ensembles of the next chapters refine it.

Pruning a grown tree back

Cost-complexity pruning, from CART, grows the tree to purity and then charges α per leaf: a subtree T scores R(T) + α|T|, with R counting training errors. Each internal node t has a price g(t) = (R(t) − R(Tt)) / (|Tt| − 1), the training errors its branch saves per extra leaf, and the cheapest branch goes first.

Growing first matters because a useless-looking split can set up good ones below it, as XOR did in chapter 1.

Choosing α without the test set

Figure 4 peeked at test error. Five-fold cross-validation instead prunes on four fifths of the training data, scores each α on the held-out fifth, and averages the five rotations. CART's one-standard-error rule takes the simplest tree within one standard error of the minimum.
