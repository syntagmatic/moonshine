Boosting

Chapter 4 of 6. Trees trained in sequence, each fit to the errors of the ones before it.

Chapter 3 averaged independent trees. Boosting adds them in sequence, each fit to what the others still get wrong.

One tree per round, fit to what is left

Start from the mean label. Each round fits a small tree to the residuals and adds a fraction ν of it:

After a few trees the residuals stop tracing a wave and the trees start fitting noise. Changing ν or the leaf count replays the same number of rounds. Try ν = 1 with 12 leaves: test error is lowest after one tree and climbs as training error falls to zero. Test error is against the true curve on a 300-point grid.

How big should each step be?

4

Figure 2. Figure 1's data boosted for 300 rounds at four learning rates, both axes logarithmic. Solid: test error against the true curve. Dashed: training error for the highlighted rate. Dots: each rate's lowest test error. In practice the stopping point comes from held-out data.

The smaller rates reach about the same lowest error, later but for longer, so stopping late costs less. At ν = 1 the minimum is higher and comes within two trees. Hence the usual recipe: small rate, many trees, early stopping.

Which leaf gets the next split?

Under a cap on leaves, XGBoost's default grows level by level; LightGBM splits whichever leaf cuts the loss most.

8

Figure 3. The first tree of Figure 1, fit to the residuals from the mean, grown two ways under one leaf budget. Circled numbers give the split order and mark the thresholds in the strip above; each leaf shows how many of the 60 points it holds.

Leaf-wise usually captures a bit more by going deeper, which LightGBM's documentation warns can overfit small data.

Does boosting remove bias or variance?

Bagging averages deep, low-bias trees to cut their variance. Boosting starts from a flat line, all bias, and adds small trees until the bias is gone, paying in variance.

50

Figure 4. Forty seeded training sets of 60 points from Figure 1's curve and noise. Bias²: squared gap between the average of the 40 fits and the true curve. Variance: spread of the 40 fits around their average. Both are averaged over x; the thin line is their sum. Left: bagging, each tree grown to single-point leaves on a bootstrap sample. Right: boosting at ν = 0.1. Logarithmic vertical axis.

That boosting wins on tabular data because real errors are mostly bias is folk wisdom, not a result. This toy problem shows the mechanism, not the winner.

Residuals are gradients

For squared loss , the residual is the negative gradient of the loss with respect to the prediction. Any differentiable loss works the same way: fit each tree to the pseudo-residuals

then give each leaf the constant that minimizes the loss on its points (mean for squared, median for absolute). Each round is a gradient step in function space.

40

Figure 5. New seeded data: smaller noise, six points pushed up by 0.9 to 1.4 (ringed). 4-leaf trees, ν = 0.1. Top: the fit and the true curve. Bottom: the pseudo-residuals the next tree will fit. Squared loss lets the outliers pull hardest; absolute loss gives every point a pull of ±1; Huber caps it at δ. Run Huber to 200 rounds: once the other residuals fall below δ, trees isolate the outliers in their own leaves and the fit chases them after all.

Friedman (1999) usually gets the credit, but Breiman's arcing papers, Friedman, Hastie and Tibshirani (1998) and Mason, Baxter, Bartlett and Frean (1999) reached boosting as optimization at about the same time.

What the libraries add

XGBoost scores splits with a second-order expansion of the loss, penalizes leaf count and leaf values, and learns where missing values go. LightGBM runs split search on binned histograms. CatBoost computes each row's category encodings and residuals only from rows before it in a random order, and grows oblivious trees, one split per level.
