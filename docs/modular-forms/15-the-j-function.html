The j-Function: The Cliff Edge into Moonshine

Part 15 of 20. j(τ) = q−¹ + 744 + 196 884 q + …. Weight 0, SL₂(ℤ)-invariant, a bijection from the modular curve to ℂ∪{∞}. The coefficient 196 884 = 1 + 196 883 is the beginning of moonshine.

The j-function is the hinge between the classical theory and Act IV. Built as the ratio of two weight-12 modular forms, its weight cancels to zero — so it is not merely covariant under SL₂(ℤ), it is genuinely invariant. Three roles ride on this single object, and the moonshine bridge depends on keeping them apart:

  1. Classifier of complex elliptic curves. Two elliptic curves over ℂ are isomorphic iff they have the same j-invariant. j is the coordinate on the moduli space.
  2. Hauptmodul for SL₂(ℤ). j generates the field of meromorphic SL₂(ℤ)-invariant functions on ℍ: every such function is a rational function of j. This "genus-zero rigidity" is what later forces the moonshine specification to fit at all.
  3. Moonshine-normalised graded dimension. Subtract the constant: J = j − 744. The coefficients of J are the dimensions of the graded pieces of the moonshine module V♮ — not of j itself. This third role is the one that points into the next part.

The j-function defined

The j-function is the ratio

E4(τ)³ and Δ(τ) are both weight-12 modular forms; their ratio is weight 0. So j is a function on ℍ/SL₂(ℤ):

An SL₂(ℤ)-invariant meromorphic function on ℍ is a modular function. j has a simple pole at i∞ because Δ vanishes there but E₄³ doesn't.

The factor 1728 = 12³ in j = 1728 E₄³/(E₄³ − E₆²) makes j(i) = 1728.

j is holomorphic on ℍ with a single simple pole at i∞. The compactified quotient X(1) = (ℍ ∪ ℚ ∪ {∞}) / SL₂(ℤ) is a genus-0 Riemann surface, and j is the isomorphism X(1) ≅ ℙ¹ — every point of X(1) gets a unique j-value (sending the cusp to ∞), which is the precise sense in which j parametrises the modular curve.

The q-expansion

Since Δ = q − 24q² + 252q³ − … starts with q (not q&sup0;), the ratio E4³/Δ starts with 1/q. The q-expansion of j is

Every c(n) for n ≥ 1 is a positive integer, growing as e4π√n/(√2 n3/4) by Hardy–Ramanujan–Rademacher. Integrality is not obvious from the definition.

c(0) = 744 is conventional. The Monster module V♮ is defined so its degree-0 piece has dimension 0, not 744; subtracting 744 gives the cleaner graded-dimension generating function (Act IV).

Why q, not τ. q = e2πiτ is invariant under T: τ ↦ τ + 1. T-invariant functions have Fourier expansions in q.

Special values

F has two orbifold points where j takes clean values:

τ = i is the square lattice (order-4 symmetry); τ = ρ = e2πi/3 is the hexagonal lattice (order-6 symmetry). These are the only lattices with extra symmetry. E4(ρ) = 0 forces j(ρ) = 0 (since j ∝ E4³); E6(i) = 0 (with E4(i) ≠ 0) gives j(i) = 1728.

Outside these special points, j is bijective on F:

ℍ/SL₂(ℤ) has genus 0, so it is the Riemann sphere; j is the isomorphism. There is one modular function with a simple pole at the cusp, up to Möbius, and j is the canonical choice.

Why the coefficients are integers

Modular functions don't generally have integer Fourier coefficients. j is special because it is a ratio of integer-coefficient modular forms (E₄ and Δ), and Δ is normalised (q-coefficient 1), so dividing by Δ stays in ℤ[[q]] after the leading q⁻¹.

The ring of modular functions for SL₂(ℤ) with integer Fourier coefficients is exactly ℤ[j].

Integer coefficients put j in arithmetic geometry. At quadratic-irrational τ, j(τ) is an algebraic integer (the singular moduli theorem, the start of complex multiplication).

Ramanujan's constant

Put τ = (1 + i√163)/2. ℚ(√−163) has class number 1 (the largest among imaginary quadratic fields), so by complex multiplication j(τ) is a rational integer:

j(τ) = q⁻¹ + 744 + O(q). For this τ, q = −e−π√163 is tiny, so q⁻¹ = −eπ√163 is a very large negative real number, and

must be an integer. So eπ√163 ≈ 640320³ + 744, differing by ~10⁻¹². This is Ramanujan's constant. Not magic: the q-tail is exponentially small when q is exponentially small, so 744 dominates.

Universal parameter for elliptic curves

Every lattice Λ ⊂ ℂ gives an elliptic curve ℂ/Λ; Λ' ≅ Λ iff Λ' = αΛ. Every lattice rescales to ℤ + τℤ for some τ ∈ ℍ, with two such lattices equivalent iff τ, τ' lie in the same SL₂(ℤ)-orbit. So:

j is a complete invariant of elliptic curves over ℂ. For any j₀, the curve y² = x³ − 27j₀/(j₀ − 1728) x − 54j₀/(j₀ − 1728) has j-invariant j₀ (j₀ = 0, 1728 need separate models).

Over ℚ, j determines the isomorphism class over ℚ̄ but not over ℚ (twists exist).

For τ a quadratic irrational, j(τ) is an algebraic integer, and ℚ(τ, j(τ)) is the Hilbert class field of ℚ(τ) — the maximal unramified abelian extension. This is complex multiplication; Ramanujan's constant is its sharpest classical instance.

The moonshine connection

Look at the first non-trivial coefficient of the j-expansion: c(1) = 196 884. In 1978, John McKay noticed something extraordinary:

196,883 is the dimension of the smallest non-trivial irreducible representation of the Monster group (order ≈ 8 × 10⁵³). c(1) = trivial rep + smallest non-trivial. The pattern continues:

  • c(2) = 21 493 760 = 1 + 196 883 + 21 296 876, where 21 296 876 is the next Monster irrep dimension.
  • Every coefficient c(n) decomposes as a non-negative integer combination of Monster irrep dimensions.

Not a coincidence. Conway and Norton (1979) conjectured a graded Monster module V♮ = ⊕n ≥ -1 Vn♮ whose graded dimension matches the shifted j-function J(τ) = j(τ) − 744 = q⁻¹ + 0·q⁰ + 196 884 q + 21 493 760 q² + …, with the convention dim Vn♮ = c̃(n) where c̃(n) is the coefficient of qn in J. (So dim V−1♮ = 1 from the q⁻¹ pole, dim V0♮ = 0 from the missing constant term, and dim V1♮ = 196 884 = c(1) from j itself.) Writing the graded dimension out:

For each Monster element g, the McKay–Thompson series Tg(τ) = Σ Tr(g|Vn) qn is the hauptmodul for some genus-0 subgroup of SL₂(ℝ). Frenkel–Lepowsky–Meurman constructed V♮ (1988) via vertex operator algebras; Borcherds (1992) proved the full conjecture using generalised Kac–Moody algebras. This is monstrous moonshine, the subject of Act IV.

Why "moonshine". Conway's name (British slang for foolish talk or illicit whisky) reflected initial scepticism. It turned out to be a gateway to vertex operator algebras, generalised Kac–Moody algebras, and string theory.

Takeaways

  • The Universal Parameter: The j-function assigns a unique complex number to every point in the fundamental domain. This number uniquely identifies any elliptic curve.
  • Explosive Growth: The coefficients of the j-function are integers that grow exponentially fast.
  • Almost Integers: Because the j-function takes on integer values at certain special points, we can use it to create bizarre numbers like Ramanujan's constant (eπ√163) which is extremely close to an integer but isn't one.
  • Monstrous Moonshine: The coefficients of the j-function precisely match the dimensions of the Monster group—a massive symmetric structure. This impossible-seeming connection launched an entirely new branch of mathematics.
