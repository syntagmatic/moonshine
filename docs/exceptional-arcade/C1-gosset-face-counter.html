C1 — Gosset Face Counter

Track C, game 1. Given a face of 421, name its count. Fluency drill for Gosset's 1900 enumeration of the 240-vertex polytope.

Drills E8 series explainer #06 The Gosset Polytope 421. If you haven't seen the face-count table yet, the game will be guesswork. Go to explainer.

Nine face classes. The 240 roots are the vertices. 6,720 edges. The middle dimensions blow up past 400,000. Then the top shrinks back, and the facets split into two orbits because 421 is uniform, not regular. By the end of a round you should be able to recite all nine counts without peeking.

How it plays

  • Each challenge names a face dimension and type. Pick the correct count from four buttons.
  • A round is 9 challenges, one per face class, shuffled.
  • Wrong answers show what the picked number is instead — that's the pedagogical payload.
  • Per-dimension accuracy is tracked so you can see which counts keep tripping you.

Tutorial. Distractors differ by orders of magnitude. You can rule them out at a glance. Goal: learn the rough scale of each dimension.
