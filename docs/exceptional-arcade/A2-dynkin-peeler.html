How it works.
  1. Read the target subsystem at the top of the stage.
  2. Click one of the 8 nodes of the Dynkin diagram to delete it.
  3. If the resulting rank-7 subsystem matches the target, you get a point. Otherwise you see which subsystem you actually produced and which node was correct.
  4. Eight challenges per round, one per distinct subsystem type.

Challenge tier reverses the direction: a component type (like E6) is given, and you must find any deletion whose subsystem contains that component.

    Notes

    The eight single-node deletions of E8 produce eight distinct rank-7 subsystems. Deleting an end of the diagram leaves a connected subsystem (E7, D7, A7); deleting an interior node or the branch produces a disconnected sum. The branch node α4 is the most dramatic: deleting it shatters the diagram into three legs (A1 ⊕ A2 ⊕ A4).

    Root counts in the table come straight from the shared library: for each deletion index i, we call E8.subsystems.byDeletion(i) and count the returned indices. Same for the Coxeter-plane highlight on correct answers — the subsystem roots are projected into the E8 mandala live, so you can see which of the 8 rings each subsystem type inhabits.
