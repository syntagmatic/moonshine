D1 · Shell Sorter

Track D, Game 1. Drop each E8 lattice vector into the shell labeled with its squared length. Fluency target: know k = ∑ xi2 without thinking.

Prerequisite. Drills Exceptional Atlas Part 14, Packing, Codes, and the Leech Lattice. Go to explainer.

The E8 lattice is infinite, but its vectors line up into neat shells — the set of vectors at a given squared length. Shell k = 2 has 240 vectors (the roots). Shell k = 4 has 2,160. This game drills the reflex of computing squared length by eye and sorting into the right shell.

Pick a difficulty, press Start round, and drag the vector tile to the correct bin. Wrong drops bounce back and show the arithmetic.

How to read the vectors

Vectors come in two flavors. Integer vectors have all coordinates in ℤ — things like (1, 1, 0, 0, 0, 0, 0, 0) with squared length 2, or (2, 0, 0, 0, 0, 0, 0, 0) with squared length 4. Half-integer vectors have all coordinates in ℤ + ½ — every entry is some odd multiple of ½.

Half-integer shortcut. If all 8 coordinates are ±½, the squared length is 8 × ¼ = 2. If six coordinates are ±½ and two are ±3/2, the squared length is 6 × ¼ + 2 × 9/4 = 6. The pattern: sum the numerators-squared and divide by 4.

The three difficulty tiers

  • Tutorial. Only two bins — k = 2 and k = 4. Every vector has integer coordinates, so squared length is a plain sum of squares. No timer. Use this to lock in the drag-and-drop mechanic.
  • Fluency. All four bins — k = 2, 4, 6, 8. Integer and half-integer vectors mixed roughly 50/50. No timer; 12 vectors per round. This is where the reflex forms.
  • Challenge. All four bins, half-integer vectors dominate, and a 20-second timer runs across the whole round of 12. Miss the clock and unsorted vectors count as wrong.
