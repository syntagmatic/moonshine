Pruning & the Spherical Diophantine Threshold

Part 7 of 15. Two short vector-norm arguments rule out every Dynkin diagram with a cycle and every node of valency > 3, collapsing the classification to a handful of shapes. A single Diophantine inequality, 1/p + 1/q + 1/r > 1, then pins the branched ones to Dn, E6, E7, E8. The list closes here.

We have the classification problem reduced to: which connected graphs with edges labelled (single, double, triple) can arise as Dynkin diagrams of positive-definite Cartan matrices? Two structural constraints do nearly all the work. First, an admissible Dynkin diagram has no cycles — it must be a tree. Second, every node in an admissible diagram has total edge weight at most 3, counting each edge with its multiplicity (single = 1, double = 2, triple = 3). Together, these rule out stars with four arms, cycles of any length, triple edges adjacent to anything else, and every other dense configuration.

What survives the pruning is a shortlist of shapes: linear chains (An), chains ending in a double edge (Bn/Cn), chains with a middle double edge (F4), the isolated triple edge (G2), and trees with one valency-3 branch whose arms still need a length bound (the D and E candidates). The second half of this explainer supplies that bound: a single Diophantine inequality on the three arm lengths (p, q, r), with exactly four solution classes — the Dn family, plus three exceptional branches E6, E7, E8. There is no fifth. The (6, 3, 2) configuration, which would give an "E9," sits exactly on the boundary where the inequality becomes equality, so it describes an affine root system rather than a finite one. E8 is the topological ceiling of the classification.

Setup: unit simple roots

Both pruning proofs are short vector-norm arguments. Given a Dynkin diagram with n nodes, pick one simple root vi at each node, normalised to unit length: (vi, vi) = 1 for every i. For a simply-laced diagram (all edges single), this costs nothing because all simple roots already have the same length and we just rescale. For a non-simply-laced diagram we rescale each root individually; this changes the Cartan integers but preserves the angles and the edge structure. What we gain is that every unit vector has (vi, vi) = 1, and pairwise inner products satisfy

The argument is tight: one extra edge would make (v, v) ≤ 0, contradicting positive definiteness.

What trees buy us. Every admissible Dynkin diagram has a unique path between any two nodes. This is what lets the Diophantine argument below reason about diagrams in terms of arms radiating from a single branch node, rather than in terms of arbitrary graph structure. Take away tree-ness, and the classification becomes wildly harder.

Valency at most 3

Claim: in an admissible Dynkin diagram, every node has total edge weight at most 3, where a single edge counts as weight 1, a double as 2, and a triple as 3.

Proof sketch. Pick a node with unit vector v, and let u1, …, uk be the unit simple roots at its k neighbours. Since the diagram is a tree, the ui are pairwise orthogonal: any path between ui and uj must pass through v, so there is no direct edge between them, and non-adjacent simple roots are orthogonal.

Project v onto the span of its neighbours. In the orthonormal basis u1, …, uk, the projection has coordinates (v, u1), …, (v, uk), and its squared length is

Now, the projection of v onto any subspace has squared length at most (v, v) = 1, with equality iff v lies in the subspace. And v certainly does not lie in the span of its neighbours (it is linearly independent from them as part of a basis of 𝔥*), so the inequality is strict:

Each term (v, ui)² equals cos²θi = (edge-multiplicity at ui)/4. Summing over all neighbours gives (total edge-multiplicity at v)/4 < 1, so the total edge weight at any node is strictly less than 4. Since edge multiplicities are integers, the total is at most 3.

This is a surprisingly sharp bound. A node can have three single edges (1+1+1 = 3), but not four. A node can have one single edge plus one double (1+2 = 3), but not two doubles (4). A node can have one triple edge and nothing else (3), but not a triple edge plus anything else. Together with the tree constraint, the shortlist collapses to:

  • Linear chains of single edges → An, arbitrarily long.
  • Linear chains with one double edge at an end → Bn/Cn.
  • Linear chains with a double edge in the middle → F4-style, length at most 4.
  • Trees with one valency-3 branch, all single edges → Dn plus the E-candidates, arm lengths still open.
  • Isolated triple edge → G2. Exactly one candidate.

The pruning constraints have reduced the classification to a shortlist of candidate shapes, but they have not said which of those candidates give actual simple Lie algebras. The branched trees with valency 3 could in principle have branches of any length, and we have not yet ruled out diagrams like a branch with arms of lengths (5, 4, 3) or (10, 2, 2). We need a final pass: a spherical Diophantine inequality that restricts the arm lengths sharply.

The T-shape

A branched tree with valency 3 at exactly one node looks like a "T" (or more properly a "Y"), a single central node with three arms radiating outward. Label the arm lengths (p, q, r), each counting the number of nodes in the arm including the branch node itself. So an arm of length p has p nodes and p − 1 edges. Without loss of generality, sort p ≥ q ≥ r ≥ 2 (the requirement r ≥ 2 is because an arm of length 1 would just be the branch node with no actual arm, reducing the tree to a valency-2 node and no fork).

The total number of nodes in such a tree is (p − 1) + (q − 1) + (r − 1) + 1 = p + q + r − 2, counting the branch node once and the other (p − 1) + (q − 1) + (r − 1) arm nodes.

This is the classification inequality. Every branched-tree Dynkin diagram of a simple Lie algebra must satisfy it, and every integer solution (with p ≥ q ≥ r ≥ 2) corresponds to an actual simple Lie algebra.

Why spherical? The inequality 1/p + 1/q + 1/r > 1 is equivalent to saying that a spherical triangle with angles (π/p, π/q, π/r) on S² has total angle sum strictly greater than π, the defining condition for positively-curved (spherical) triangles, as opposed to flat (Euclidean, sum = π) or negatively-curved (hyperbolic, sum < π). The same inequality appears in the classification of finite Coxeter groups, of Platonic solids, of spherical tilings, and of regular polyhedra, it is a remarkably universal bound for "finite positively-curved combinatorial objects."

The only solutions are the infinite Dn family (q = r = 2, any p ≥ 2) and three singleton exceptions (5, 3, 2), (4, 3, 2), (3, 3, 2) corresponding to E8, E7, E6. The (4, 4, 2) and (3, 3, 3) configurations are boundary cases where the inequality becomes equality, those correspond to affine Kac-Moody algebras rather than finite-dimensional simple Lie algebras.

So the complete solution set is:

  • Dn for n ≥ 4: the (p, 2, 2) family with p = n − 2 ≥ 2. A branch with two length-2 arms and one variable-length arm. The arm count p plus 2 gives the rank of the D algebra, so D4 has arm triple (2, 2, 2), D5 has (3, 2, 2), and so on.
  • E6: arms (3, 3, 2). A rank-6 algebra with a perfectly symmetric (3, 3, 2) branch.
  • E7: arms (4, 3, 2). Rank 7.
  • E8: arms (5, 3, 2). Rank 8. The largest finite-dimensional simple Lie algebra in the ADE family.

That is all the branched-tree Dynkin diagrams. No other triples (p, q, r) give finite Cartan-matrix positive-definite solutions.

The classification is complete

Putting together everything from Act II:

  • Linear chains of single edges → An, one per n ≥ 1.
  • Chain with one double edge at the end → Bn, one per n ≥ 2. By reversing the arrow, → Cn, one per n ≥ 3.
  • Chain with a double edge in the middle, length at most 4 → F4 (and only F4, longer chains fail the valency-type bound on the central region).
  • Isolated triple edge → G2, the only rank-2 exceptional.
  • Branched trees with a single valency-3 node and simply-laced edges → Dn from (p, 2, 2); E6 from (3, 3, 2); E7 from (4, 3, 2); E8 from (5, 3, 2).

These nine families, A, B, C, D, E6, E7, E8, F4, G2, are the complete list. Every other connected Dynkin-diagram shape either has a cycle, a valency-4 node, a multiple edge with another multiple edge or a branch, or an arm configuration that fails the Diophantine bound. Why (6, 3, 2) fails

The (6, 3, 2) configuration deserves a second look, because it is so close to working. Compute: 1/6 + 1/3 + 1/2 = 1/6 + 2/6 + 3/6 = exactly 1. The Diophantine inequality demands strict inequality, and (6, 3, 2) gives equality. So the Cartan matrix associated with (6, 3, 2) is positive semi-definite but not strictly positive definite, one of its eigenvalues is zero. That means the associated "Lie algebra" is not a finite-dimensional simple Lie algebra in the Cartan-Killing sense.

What it is is the affine Kac-Moody algebra Ẽ8, an infinite-dimensional Lie algebra obtained by adjoining an "affine node" to the E8 Dynkin diagram. Affine Kac-Moody algebras are central to 2D conformal field theory, integrable systems, and the monster-moonshine story; the Moonshine act (Parts 16–20) of the Modular Forms series picks up exactly this thread. For our classification, what matters is that affine Kac-Moody algebras sit right on the boundary between the finite classification and infinity: the Diophantine inequality strict/equality cutoff, plus the next step into hyperbolic Kac-Moody when the sum drops below 1, spans three increasingly wild regimes.

For the Cartan-Killing classification, we stay on the strict-greater-than side, and E8 is the largest we get.

Takeaways

  • Tree constraint. Any admissible connected Dynkin diagram has n − 1 edges on n nodes — it is a tree. The proof uses |v1 + ⋯ + vn|² > 0 and the fact that each edge contributes −√(mult) ≤ −1 to the double sum.
  • Valency constraint. Any node has total edge weight at most 3. The proof projects the central node onto an orthogonal basis of its neighbours and uses Σ (cos²θi) < 1, forcing (total weight)/4 < 1.
  • The Diophantine inequality. For a branched-tree Dynkin diagram with arm lengths (p, q, r) (counting nodes from tip to branch), positive-definiteness of the Cartan matrix is equivalent to 1/p + 1/q + 1/r > 1.
  • Solution set. The inequality has the Dn infinite family (q = r = 2) and exactly three exceptional branched solutions: E6 = (3, 3, 2), E7 = (4, 3, 2), E8 = (5, 3, 2). The (6, 3, 2) point sits on the boundary and corresponds to the affine Kac-Moody Ẽ8.
  • F4 and G2. The non-simply-laced cases are handled by the analogous short finite check on double-edge placement (for F4) and the isolated triple edge (for G2). Each produces exactly one diagram.
  • The full list. Nine families total: An, Bn, Cn, Dn (four infinite families), E6, E7, E8 (three exceptional branched simply-laced), F4 and G2 (two non-simply-laced exceptions). Act III visits each of the five exceptions in turn.
