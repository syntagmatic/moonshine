String Diagrams: Wiring Algebra

Part 7 of 14. A graphical calculus for monoidal categories: objects become wires, morphisms become boxes, and the topology of the picture encodes every algebraic equation.

Play: Build string diagrams. Choose a preset to see its string diagram. Drag any box to rearrange — the wires follow. See how composition stacks vertically and tensor products sit side-by-side.

The Core Concept

Most mathematical notation is one-dimensional. g ∘ f means "first f, then g," but the composition is invisible. String diagrams make the wiring explicit. Every wire carries a type (an object in a monoidal category), every box carries a morphism, and the geometry of the picture is the algebra.

A monoidal category is a category equipped with a tensor product and a unit object, satisfying coherence conditions. Every equation in a monoidal category can be stated as a topological deformation of a string diagram. Two diagrams represent the same morphism if and only if one can be continuously deformed into the other.

The visual dictionary: In string diagrams, reading flows top to bottom.

  • Objects are wires — vertical lines.
  • Morphisms are boxes — rectangles sitting on wires, with input wires entering from the top and output wires exiting at the bottom.
  • Composition (applying f then g) is vertical stacking: connect the output wires of f to the input wires of g.
  • Tensor product (f ⊗ g) is horizontal juxtaposition: place f and g side by side.
  • Identity is a bare wire with no box.

Braiding and symmetry: In a braided monoidal category, objects can cross past each other. The braiding swaps two wires, drawn as a crossing. In a symmetric monoidal category (like vector spaces), the two crossings are equal.

Duals: cups and caps: When an object A has a dual A*, we gain two special morphisms: the unit (cup) and the counit (cap). These satisfy the snake identities (S-bends can be straightened). The trace of a morphism is constructed by bending a wire from an output back to an input using a cup and a cap.

Worked Examples

Linear algebra: A morphism is a matrix. Composition is matrix multiplication. Tensor product is Kronecker product.

Quantum circuits: A quantum gate is a unitary morphism on a tensor product of qubit spaces. Composing gates is vertical stacking; running independent gates in parallel is horizontal juxtaposition.

Signal flow: The braiding lets signals cross, and the trace construction models feedback loops: the same cup-cap that gives matrix trace gives the transfer-function feedback formula.

Concept Summary

  • Composition: Vertical connection (outputs feed inputs).
  • Tensor product: Horizontal juxtaposition (independent processes side by side).
  • Braiding: Wire crossings (the swap isomorphism made visible).
  • Duals: Cups and caps (wires bend to create units and counits).
  • Trace: Feedback loops (output wires routed back to inputs via cup-cap pairs).
  • Equations: Topology (two diagrams represent the same morphism iff one deforms into the other).
  • Coherence: Invisible isomorphisms (associators and unitors are absorbed into the geometry).
