A diagram is a presentation, not a proof. The arrows you draw are generators; the equalities you declare are relations. Nothing in the picture forces g ∘ f to equal h. “This diagram commutes” is a claim its author adds on top of the picture, which is why papers have to say it out loud. The Core Concept

Category theory studies the maps between objects. With several objects and several maps, equations like g' f = f' g become opaque. A commutative diagram makes the same statement visible: objects as nodes, maps as arrows, every directed path between two nodes yielding the same composite.

A category consists of a collection of objects and, for every pair of objects, a set of morphisms (arrows) between them. Every object has an identity morphism, and morphisms compose associatively.

A commutative diagram is a finite directed graph embedded in this framework. Nodes are objects. Directed edges are morphisms. The intended subdiagrams commute when the relevant directed paths from the same source to the same target have equal composites.

Commutativity is about paths, not shapes. A square commutes when top-right equals left-bottom; a triangle commutes when the direct edge equals the two-step detour. The path algebra is the content.

Arrow styles: The style of an arrow is not decoration. A plain arrow (→) is a morphism with no additional claim. A hooked arrow is a monomorphism (injective). A double-headed arrow is an epimorphism (surjective). A dashed arrow asserts the existence (and often uniqueness) of a morphism.

Concept Summary

  • Square: Two different compositions of morphisms are equal (e.g., naturality condition).
  • Triangle: A morphism factors through an intermediate object.
  • Exact sequence: The image of each map is the kernel of the next.
  • Product diagram: A universal construction defined by a unique fill-in dashed arrow.
  • Snake lemma: Two linked exact sequences produce a connecting homomorphism.
  • Path agreement: Commutativity is not about shapes but about the path algebra: every pair of directed routes between two nodes composes to the same morphism.
  • Generators and relations: A drawn diagram presents a category: arrows are generators, and each declared equality of composites is a relation. Commutativity is asserted, then used.
