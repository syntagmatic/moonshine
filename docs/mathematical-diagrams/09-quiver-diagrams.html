The Core Concept

A quiver is a directed graph: a finite set of vertices and a finite set of arrows, with multiple arrows and, in general, loops permitted. Many finite-dimensional algebras can be presented as path algebras of quivers with relations, and their representation theory connects graph combinatorics to homological algebra, Lie theory, and cluster algebras.

The path algebra: Given a quiver and a field, the path algebra is the algebra whose basis consists of all directed paths in the quiver. Multiplication is concatenation when paths meet and zero when they do not.

Quiver representations: A representation of a quiver assigns a vector space to each vertex and a linear map to each arrow. Gabriel's theorem (1972) proved that a connected quiver has finitely many indecomposable representations if and only if its underlying undirected graph is an ADE Dynkin diagram.

Cluster algebras and mutation: Fomin and Zelevinsky introduced cluster algebras in 2002. The combinatorial engine behind a cluster algebra is quiver mutation. Given a quiver without loops or 2-cycles and a vertex k, the mutation produces a new quiver by three steps:

  1. For every pair of arrows i → k → j, add a new arrow i → j.
  2. Reverse all arrows incident to k.
  3. Cancel any resulting 2-cycles.

Mutation is an involution: mutating twice at the same vertex returns the original quiver. The mutation class of a quiver is a fundamental invariant.

Concept Summary

  • Vertices: Basis idempotents of the path algebra, or simple modules.
  • Arrows: Generators of the radical: each arrow is an irreducible morphism between simples.
  • Paths: Composition of morphisms: the path algebra is spanned by all directed walks.
  • Orientation: Algebra structure: different orientations of the same underlying graph yield non-isomorphic algebras with equivalent derived categories.
  • Mutation: Tilting equivalences: mutating a quiver corresponds to a change of tilting object in the derived category.
  • Finite type: Dynkin classification: finitely many indecomposables iff the graph is ADE.
  • Cluster variables: Laurent polynomials: each mutation step produces a new rational function that is miraculously a Laurent polynomial.
