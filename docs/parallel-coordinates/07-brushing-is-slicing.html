Brushing Is Slicing

Each kind of brush cuts a slice through the data space, and the shape of the slice decides what you can select.

Brushing is the main interaction in parallel coordinates: drag a range on an axis to select the polylines that pass through it. Geometrically, it slices the data space with hyperplanes and keeps the points in between.

The shape of the region depends on the brush type. Axis brushing produces rectangles. Angular brushing, which selects by segment slope between axes, produces wedges.

Axis Brushing = Hyperplane Slice

Selecting a range on axis selects all data points where . Geometrically, this is slicing the data space with two parallel hyperplanes perpendicular to the axis.

In two dimensions the hyperplanes are vertical or horizontal lines. In higher dimensions each axis brush is a slab, an infinite region between two parallel planes, and the selected points are the ones inside it.

Multi-Axis Brushing = Intersection of Slices

Brushes on several axes combine by intersection, each one adding a constraint. If you brush axis to select and axis to select , the selected points satisfy both conditions. The region in data space is a hyperrectangle, the Cartesian product of the individual intervals.

In the scatterplot view, a brush on one axis is a band; a second axis adds a perpendicular band; the intersection is a rectangle. Axis brushing always produces axis-aligned selections.

Angular Brushing = Slope Selection

Angular brushing works on the segments between two axes. You draw a line in the gap (a "strum"), and it selects every polyline whose segment crosses it.

By the duality, a segment's slope encodes the relationship between the two variables, so a strum constrains that relationship directly.

The Wedge: Two Strums Define a Region

A second strum line between the same pair of axes defines a wedge. The selected polylines are those whose segments pass between the two lines, which means their slopes fall in a range.

In the scatterplot this is a wedge-shaped region that selects points by angle, something no axis brush can do.

Where is the axis spacing and encodes the slope of each polyline segment. Two strum lines at different angles bound a range of slopes, selecting a wedge in the scatterplot.

Drag between the two axes to draw a strum line; a second strum defines a wedge. Tap a strum to remove it.

Figure 2. A strum line between two axes selects every segment that crosses it. Two strum lines define a wedge, and the linked scatterplot shows the region it selects.

Axis brushing selects a value range on each axis, which gives rectangles in any 2D projection of the data. Angular brushing selects by the ratio between variables, which gives wedges, and a wedge can tightly bound a cluster that lies along a diagonal.

A near-vertical strum drawn close to an axis behaves almost like a brush on that axis, so strums can approximate rectangular selections. The reverse fails: no combination of axis brushes expresses a diagonal wedge. In that approximate sense angular brushing can do more.

Combined Brushing

Used together, axis brushes constrain individual variables and strums constrain relationships between them, which isolates regions neither can reach alone.

Brush axes and draw strum lines to isolate clusters. Axis brushes filter by value; strums filter by slope.
