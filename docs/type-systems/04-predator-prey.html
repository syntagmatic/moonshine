Predator and Prey

Two species oscillate. One newtype with a refinement predicate tells the type checker, and the eye, that populations cannot fall below zero. The predicate draws the walls of the phase portrait.

§1 · Cold sim

Two populations chasing each other around a fixed point

Prey grow when left alone; they are eaten when predators find them. Predators starve without prey; they breed when prey are plentiful. The two counts oscillate, and the trail of the state in (prey, predator) space loops around a single fixed point forever.

§2 · Name the types

A sum for species, a refinement for populations

Two moves. First, species is a sum type, the same fork container we introduced for constraints but with two bands instead of three. Second, population is a newtype around a double with a refinement predicate: the number must be non-negative. A value of type Pop that is negative is, by construction, not a value of type Pop.

data Species = Prey | Predator newtype Pop = Pop Double where { p | p >= 0 } -- refinement predicate data State = State { prey :: Pop, pred :: Pop } data Params = Params { alpha :: Double -- prey birth rate , beta :: Double -- predation rate , gamma :: Double -- predator death , delta :: Double -- predator birth per prey eaten }

Refinement types are predicates the type checker carries with the value. No runtime if n < 0 then error scattered through the step function: the predicate lives in the type, and every constructor and combinator producing a Pop preserves it.

A Pop is a half-line, not a line. A State is a quadrant, not a plane. Refinement types are boundaries in state space.

§3 · Signature diagram

A Species picks the rule; Params and State flow through

The one-species update rule takes a species tag, the parameter bundle, and the current state, and returns the new state. The sum type on the left is the species, two variants colored by extension palette. TV.sum renders it the same way it did for constraints; the fork container is now part of the shared vocabulary.

rateFor :: Species -> Params -> State -> Double rateFor Prey (Params a b _ _) (State p q) = a * p - b * p * q rateFor Predator (Params _ _ c d) (State p q) = -c * q + d * p * q step :: Params -> State -> State step ps s = State (clamp (prey s + dt * rateFor Prey ps s)) (clamp (pred s + dt * rateFor Predator ps s))
Second appearance of TV.sum: the species fork feeds the rate selector. Params and State enter as products, and a State' pipe leaves on the right. The clamp stage is where the refinement predicate is enforced — and in a real refinement-typed language, the type checker would prove it rather than runtime-check it.
§4 · What it lets you say

The predicate is a wall

Here is the payoff. The phase portrait lives in the (prey, predator) plane. The refinement predicate says p >= 0 for both coordinates. That predicate is the two axes: the non-negativity wall along x = 0, and the one along y = 0. Four trajectories seeded at different points all orbit the fixed point, and none of them cross the walls. The type system says they never can.

Four orbits around the Lotka-Volterra equilibrium. The dashed amber walls are the refinement predicate Pop >= 0 rendered literally into state space via TV.wall. A trajectory that touches a wall is a population that reaches zero — extinction — and a refinement-typed simulation is one where that boundary is proved unreachable from any starting state you can construct.

A type predicate is a shape; the shape is drawable. The program's state space is a mathematical object, and refinement types put the drawing on the page.

The mean-field ODE of §1 has smooth oscillations because of the well-mixed assumption. Real ecosystems are spatial: a predator can only reach adjacent prey. Put the same rules on a lattice and as the predation rate λ crosses a critical value the system undergoes an active-to-absorbing phase transition whose cluster geometry belongs to the directed percolation universality class. The ODE cannot see this; the lattice admits it as structure.

The critical curve λc(σ) separates an active phase where predator clusters persist from an absorbing phase where predators die out and prey fill the lattice. The two thumbnails are live contact-process lattices running at either side of the line. The type signature of this simulation is not "ODE that preserves a population quantity" but "lattice model whose step flows toward one of two absorbing classes, indexed by a phase label."

The phase is the right type. Two macroscopic populations on a half-plane is one class of simulation; a 2D lattice flowing toward one of two absorbing regimes indexed by where (σ, λ) sits relative to the critical curve is a different class, with different laws. Continuous-time RG analysis shows the critical exponents at λc match those of forest-fire propagation, lattice epidemic thresholds, and wetting fronts. A universality class is a type.

The two-species sum extends to a three-species rock-paper-scissors cycle (A eats B, B eats C, C eats A), bringing the cyclic Z₃ to the substrate as a subgroup of the S₃ permuting species labels. On a lattice the ecosystem forms macroscopic spiral waves; any update rule that quietly favours one species breaks Z₃ and collapses the spirals into monoculture. The instability is in the update loop, not the biology.
