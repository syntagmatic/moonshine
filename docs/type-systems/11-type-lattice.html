The Type Lattice as Geometry

The ten signatures we've built don't just describe ten programs, they are ten points in a nine-dimensional space. The shape they trace in parallel coordinates is the geometry we've been promising.

§1 · Type first

A signature is a point

The meta-move: we built ten signatures, and now we type them. A Signature is a record whose fields count the compile-time phenomena visible in a function's type.

data Signature = Signature { arity :: Nat -- value-level arguments , sum :: Nat -- largest sum-type variant count , prod :: Nat -- largest product-type field count , eff :: Nat -- effect rank (Det / Rand seeded / Rand / IO) , shape :: Nat -- type-level shape parameters , refine :: Nat -- refinement predicates , phantom :: Nat -- phantom type parameters , invar :: Nat -- preserved invariants , traits :: Nat -- trait / typeclass constraints }

Reading left-to-right, each signature becomes a path through the dimensions. Lines that share a shape share a type-geometric profile; lines that spike on a dimension nobody else touches mark concepts this series only introduced once.

Two signatures are close when their records agree on most fields. They are comparable when one record's fields all dominate another's. Read through Curry-Howard, a signature can also be treated as a proposition about what kind of implementation may inhabit it.

§2 · Signature diagram

The Signature type, drawn

The signature-diagram primitive is meta here. What we draw is not a function's type but the type of every function's type, a product with nine named components.

Nine named pipes inside a single Signature product. Each is a Nat; each corresponds to an axis of the parcoords above. The product type is the coordinate system.
§3 · What it lets you say

The signature space is projecting a real classification

The nine-axis space echoes a classification that already has a canonical mathematical form. For periodic Euclidean lattices, International Tables for Crystallography tabulates 17 plane groups, 230 space groups, and 32 crystallographic point groups. The counts are finite because symmetry constrains the geometry.

The 5 Bravais lattice classes of 2D. #9's Gray-Scott argument, in this language, is that confusing square and hex-like symmetry can leave artifacts parameter tuning cannot remove. #2's graph-automorphism argument is that a leader cannot distinguish followers lying in the same orbit. #12 descends one more rung to root systems, where finite reflection symmetries become explicit.

Two observations from the data. First: signatures cluster along family colors because related articles tend to reuse the same type devices. Second: the 2D shadow below shows that the ten signatures do not fill the nine-dimensional space. They occupy a small, structured sample.

Each dot is one explainer's signature, projected from 9D onto the two directions of maximum variance. Signatures in the same family often land near each other. This is an exploratory shadow, not a theorem; it tells us where the series has repeated structure.

One structural claim extends the classification: the nine-axis space carries a natural partial order. Signature A ≤ Signature B when every component of A is ≤ the corresponding component of B. This turns the ten points into a Hasse diagram of realized signatures. #12 studies the finite reflection groups that can act on such point configurations.
