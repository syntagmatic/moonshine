The Type Lattice as Geometry

The ten signatures we've built don't just describe ten programs — they are ten points in a nine-dimensional space. The shape they trace in parallel coordinates is the geometry we've been promising.

§2 · Name the types

A signature is itself a value. Its type is a product of nine naturals.

The meta-move: we've built ten signatures, and now we type them. A Signature is a record whose fields count the compile-time phenomena visible in a function's type. Two signatures are close in the lattice when their records agree on most fields; they are comparable when one record's fields all dominate another's.

data Signature = Signature { arity :: Nat -- value-level arguments , sum :: Nat -- largest sum-type variant count , prod :: Nat -- largest product-type field count , eff :: Nat -- effect rank (Det / Rand seeded / Rand / IO) , shape :: Nat -- type-level shape parameters , refine :: Nat -- refinement predicates , phantom :: Nat -- phantom type parameters , invar :: Nat -- preserved invariants , traits :: Nat -- trait / typeclass constraints } classify :: (Function f) => f -> Signature

The function classify is the thing this explainer is secretly demonstrating. Run it on tick from #1 and you get a Signature with phantom=1 and zeroes elsewhere. Run it on step from #10 and you get traits=3, eff=1. The parcoords above is map classify applied to the series.

Under the Curry-Howard reading every signature is a proposition — "there exists a function of this shape, respecting these invariants, carrying these phantom tags." Every implementation underneath it is a proof that the proposition is inhabited. The ten lines overhead are therefore ten theorems the series has already settled; the nine-axis space is their shared vocabulary.

§4 · What it lets you say

The signature space is projecting a real classification

The nine-axis space above is the type-theorist's sketch of a classification that already has a canonical mathematical form. The symmetry group of a simulation's state space is not arbitrary: in 2D it has to be one of 5 Bravais lattices / 10 point groups / 17 wallpaper groups; in 3D, one of 14 / 32 / 230. That is a finite classification, and every well-posed physical simulation is a program whose state-space symmetry is one of its elements. The parcoords on this page is that classification projected onto nine made-up axes; the figure below is a slice of the actual one.

The 5 Bravais lattices of 2D — every flat simulation's allowable symmetry is one of these. #9's Gray-Scott argument, in this language, is that confusing p4m for p6m wrecks the macroscopic physics regardless of parameter choice. #2's graph-automorphism argument is that a leader cannot distinguish followers lying in the same orbit of the lattice's point group. #12 descends one more rung to the root systems A₂, …, E₈, where the lattice is so symmetric it becomes a fixed point of the classification itself — and is directly expressible as a finite sum type.

That's the destination. Back to the data on this page: two observations. First, the signatures cluster along the family colors — not because we plotted them that way, but because simulations with similar symmetry groups end up with similar signatures, and the nine axes we chose are sensitive enough to detect it. Second, the 2D PCA shadow below shows the ten signatures do not fill the nine-dimensional space. They live on a low-dimensional manifold, and the shape of that manifold is what the Bravais classification makes rigorous.

Each dot is one explainer's signature, projected from 9D onto the two directions of maximum variance. Signatures in the same family land near each other. The shape is not yet a root system — but it is closer to one than to a random cloud, and that is the evidence the Bravais classification exists for this series.

One structural claim extends the classification: the nine-axis space carries a natural partial order. Signature A ≤ Signature B when every component of A is ≤ the corresponding component of B. This turns the ten points into a Hasse diagram — a subtype lattice of realized simulations — and #12 is what you get when you find the symmetries of such a lattice: a finite reflection group acting on a point configuration.

§5 · Carry-forward

We added. lib/signatures.js — a single authoritative record of every explainer's signature and its nine-dimensional coordinate. Future additions to the series populate one row; everything on this page redraws.

Where this goes. The shape the ten signatures trace has a name in mathematics. When a finite set of points sits in a symmetric space and is closed under reflections through its midpoint, the set is a root system. #12 works the smallest non-trivial root system — A₂ — fully, and shows four simulations from earlier in the series whose symmetries are exactly the Weyl group of A₂. That's where the thesis — programs have geometry — becomes a theorem instead of an observation.
