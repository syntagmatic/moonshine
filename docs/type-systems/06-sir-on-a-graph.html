SIR on a Graph

The force layout from #1 returns, this time carrying compartments. An indexed sum type labels each node, and a population-level refinement |S| + |I| + |R| = N makes the admissible state space a triangle.

§1 · Type first

Three labels, one conserved population

The SIR state is a contact graph whose nodes carry one of three labels: S, I, or R. The labels come from Kermack and McKendrick's epidemic model; here they live on vertices, not in a well-mixed population.

data Compartment = S | I | R data Node = Node { id :: NodeId , pos :: Position , comp :: Compartment , t :: Time } -- time of last transition type Population = Map Compartment Int -- Refinement on the population distribution: refined :: { p :: Population | sum p == N }

The sum type on Node.comp is local. The refinement on Population is global. The only transitions are S → I and I → R, so each update changes labels without changing the total.

§2 · Signature diagram

Rates in, graph through, graph out

The step function is a function of two rates (the transmission probability and the recovery rate) and the current graph, a product of a node list and an edge list. The sum on the left now shows up inside the node record: each node's comp field is a three-way fork.

step :: Rates -> Graph -> Graph where Rates = { beta :: Scalar, gamma :: Scalar } Graph = { nodes :: [Node], edges :: [Edge] }
Left: the Compartment sum living inside each node. Middle: the Graph product (nodes × edges) feeding the step box. Right: live counts from §1, proving the output still lands in the same population refinement.
§3 · What it lets you say

The admissible states form a triangle

The refinement |S| + |I| + |R| = N with non-negative counts is the standard 2-simplex: a triangle whose vertices are the pure states and whose interior is every legal mixture. Every reachable configuration sits in this triangle.

Below: the §1 sim, with (|S|, |I|, |R|) rendered as a barycentric point. The dashed boundary is the simplex itself.

The live trajectory sweeps from the S corner (pre-epidemic) toward the R corner (post-epidemic), bowing into the triangle as I spikes. The wall is the type — no algorithm in this sim needs to check sum == N because no update moves the point off the triangle.

The conservation law is the type's arithmetic. The graph's topology is a second type parameter. Same β, patient zero, and γ: a lattice tends to grow a spatial front; a regular ring sends a wave around the cycle; a Barabási-Albert network routes spread through hubs. These differences in morphology are carried by Graph (Topology t).

Three SIR simulations seeded identically. β and γ are shared; only the graph topology differs. Work on scale-free epidemic spreading, such as Pastor-Satorras and Vespignani, is one reason topology belongs in the signature. A policy whose signature requires a lattice-front model should not accept a scale-free Graph without an explicit adapter.
§4 · Carry-forward

We added. The series' first sim inheritance: #1's force layout returned here specialized with compartment labels, the same repulsion + link-spring + centering physics carrying disease-dynamics state. Three compartment colors (S light-blue, I orange, R teal) named in the extension palette. The idea that a refinement type can carve out a geometry in state space, not just a predicate on a scalar. And a Topology type parameter naming which lattice or network the dynamics live on (spatial lattice, regular ring, scale-free), each producing a qualitatively distinct percolation cluster morphology from identical rates.
