§2 · Name the types

Three labels, one conservation law

A Compartment is either S, I, or R. Unlike #3's Constraint, these variants carry no payload — they're pure labels. But a second type lives one level up: the population distribution, refined so its three counts sum to the fixed population size.

data Compartment = S | I | R data Node = Node { id :: NodeId , pos :: Position , comp :: Compartment , t :: Time } -- time of last transition type Population = Map Compartment Int -- Refinement on the population distribution: refined :: { p :: Population | sum p == N }

The sum on Node.comp is the indexed part — every individual carries its label. The refinement on Population is the geometric part — it lives not on any one node but on the whole system. Conservation isn't enforced by checking it each frame; it's a property of every reachable state because the only transitions are S → I and I → R, both of which leave the sum unchanged.

Rates in, graph through, graph out

The step function is a function of two rates (the transmission probability and the recovery rate) and the current graph — a product of a node list and an edge list. The sum on the left now shows up inside the node record: each node's comp field is a three-way fork.

§4 · What it lets you say

The admissible states form a triangle

Here is the geometry argument. The refinement |S| + |I| + |R| = N with non-negative counts is — geometrically — the standard 2-simplex: a triangle whose three vertices are the three pure states ("all susceptible", "all infected", "all recovered"), and whose interior is every legal mixture. Every reachable configuration of the population sits somewhere in this triangle, never outside.

Plotted below is the same sim from §1, with the current (|S|, |I|, |R|) rendered as a barycentric point. The dashed boundary is the simplex itself — the type's shape in state space.

The live trajectory sweeps from the S corner (pre-epidemic) toward the R corner (post-epidemic), bowing into the triangle as I spikes. The wall is the type — no algorithm in this sim needs to check sum == N because no update moves the point off the triangle.

The conservation law is a dependent equality: the type of a post-update population carries the predicate s + i + r = N as part of its definition, and the update function has to deliver a witness for that equality on every call. A proof assistant closes this by induction on the step — one generic argument, all trajectories protected for all time. The triangle also has an unforced S₃ symmetry when the three compartments are interchangeable; #12 is where that latent group action becomes the subject.
