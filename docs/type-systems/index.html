Type Systems for Simulation

Interactive explorations of how structural code choices shape the visual behavior of simulations.

Primary thesis. The structure of your code is a shape you can see.

Method. We assign colors and geometry to the abstract structures underneath your code.

Payoff. You'll see how rigid, careful programming patterns translate into beautiful, guaranteed behaviors in physics and logic.

The palette

Six reserved colors carry across all twelve explainers, so you can read the mechanics of a simulation at a glance.

The series

Watch how code rules snap together. We start with simple forces, move through state machines, and end by visualizing code architecture itself as a spatial map.
