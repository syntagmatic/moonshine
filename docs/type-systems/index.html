Type Systems for Simulation

Twelve force systems, state machines, fields, and lattices — rebuilt with the type discipline made visible. The claim: programs have geometry.

Primary thesis. The state space of a well-typed simulation is a mathematical object you can visualize.

Method. Types as a design language: every signature renders as an animated diagram, every atomic type has a reserved color.

Ratchet. Each explainer earns its type construct with an expressiveness payoff — a combinator that falls out for free, a composition that only works because the shapes line up.

The palette

Six reserved atomic-type colors carry across all twelve explainers. By the third piece you read the sim as a type-colored scene at a glance.

The series

The first three explainers forge the shared lib on force systems. The middle seven climb through state machines, conservation laws, effects, and shapes. The last two pivot: types as a space, then as a root system.
