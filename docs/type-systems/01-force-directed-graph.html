§3 · What it lets you say

Phantom types: Node Fixed versus Node Free

Beyond preventing mistakes, the discipline gives us vocabulary. A phantom type tag separates nodes the integrator is allowed to move from nodes it must leave alone. The integrator's signature refuses the illegal call, with no runtime guard needed.

data Fixed ; data Free integrate :: Delta Time -> Node Free -> Node Free -- integrate _ (n :: Node Fixed), rejected at the type level

Accepted · Node Free

Rejected · Node Fixed

Same integrate function, two candidate inputs. The Free pipe socket-connects; the Fixed pipe approaches but is refused — no runtime guard, no conditional, just the type.

Phantom tags are the simplest lattice in the series: a discrete classification of nodes into kinds, with the kind controlling what can act on the value. Two-element {Fixed, Free} here, three-element {S, I, R} in #6, six-element {Moving(Speed), Braking(Decel), Stopped} in #5, 240-element root system in #12. Each lattice comes with a group that acts on it (trivial here, S₃ permuting SIR compartments later, C₆ᵥ for a hex stencil, the Weyl group of A₂), and step must be invariant under that action.

§4 · Spatial index as type

The lattice under the simulation

Every force tick asks "which nodes are near this one?" The naïve answer costs O(N²). Two standard fixes (quadtree and spatial hash) are the same idea on different lattices: the quadtree is a hierarchical lattice refining where particles cluster; the spatial hash is a flat lattice whose translational symmetry collapses a 3-D coordinate into a 1-D bucket index. A type names the choice, making the index part of the scene graph rather than a side effect of the neighbor loop.

data SpatialIndex a = Quadtree (BBox a) [a] | Hash (GridCell a) (CellSize s) | None [a] neighbors :: SpatialIndex a -> Position -> [a] -- None → O(N) per query · full scan -- Quadtree → O(log N) per query · tree descent -- Hash → O(1) per query · hash lookup

Same 30 nodes, two indices. Left subdivides when a cell holds more than two nodes — denser branching follows the crowd. Right stamps a fixed grid across the domain and the hash function sorts positions into buckets by integer coordinates, which is translational symmetry of the lattice doing the algorithmic work.

Every lattice structure downstream (hexagonal boid neighborhoods, Gray-Scott stencil, Ising hypercubic grid, Lattice Boltzmann hex) is the same move. Pick a discrete subgroup of the continuous symmetry you care about, let the type name it, and the algorithm inherits the geometry.
