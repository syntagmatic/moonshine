Grundy Values and mex

Part 3 of 15. Every impartial game position carries a single number that tells you everything strategic about it. The number comes from a one-line recursive formula, and the operator hiding inside that formula takes about ninety seconds to learn.

In the first two explainers we played Nim and Green Hackenbush. Each game had its own quirks, its own winning pattern, its own little party trick: XOR the heap sizes for Nim, colon-sum the branches for Hackenbush. Fine for two games. Hopeless as a strategy for the dozens of impartial games still ahead of us in this series.

This explainer introduces the operator that unifies all of them. It is called mex, it takes a set of non-negative integers, and it returns the smallest non-negative integer not in that set. From this single operator we build the Grundy value of any impartial game position, a non-negative integer that encodes the complete strategic content of the position. Same Grundy value means the two positions play identically. Grundy value zero means the player to move is losing. That is all you will need to know.

Figure 1. The mex operator, by hand

Here is the full specification. Take a finite set S of non-negative integers. Ask: what is the smallest non-negative integer that is not in S? Whatever that integer is, that is the mex, the minimum excludant.

Figure 1. The mex operator is a search: start from 0, walk upward, stop when you find an integer that is not in the set. Empty set gives . A set containing 0, 1, 2 gives . Crucially, mex does not care how many elements the set has; it only cares which low integers are missing.

Notice a few things. Mex ignores gaps above the first hole. The set has mex 1, not 4: as soon as the scan finds a missing integer, it stops. Mex of the empty set is 0, because 0 is already missing before you even start. And mex never fails, no matter what finite set you feed it, there is always a smallest missing non-negative integer to return.

That is the entire operator. Spend a minute on the chips. If you can compute mex of a set of at most ten integers in your head, you already know enough to compute the Grundy value of any impartial game you have played so far.

From mex to Grundy values

A game is a tree (technically a DAG, but let's think of it as a tree for now) of positions. Every non-terminal position has a set of options, the positions you can move to in a single legal move. Every terminal position, by definition, has no options at all: the player to move has lost.

Read that aloud. "The Grundy value of a position is the mex of the Grundy values of its options." Terminal positions have no options, so their Grundy value is the mex of the empty set, which is 0. Every other position is computed recursively from its children: look up their Grundy values, collect them in a set, take the mex.

That is the whole theory. Two short sentences and you are done. The rest of this explainer is practice, and proof that this simple formula is the complete description of impartial-game strategy.

A few observations from Figure 2. Every leaf is 0 because a player who has no moves has lost. Internal nodes whose children are exactly get value 3, matching the mex rule. The root of this particular tree has Grundy value 4, which means it is a first-player win (any nonzero value is). If you scan the tree for nodes with Grundy value 0, those are the losing positions: whichever player finds themselves on one of those nodes with the move to make is about to lose against optimal play.

Why bottom-up? The recursive definition can only evaluate a node once all its children are known. In a DAG, that means topological order: start from the leaves (depth zero) and sweep upward. Memoization collapses duplicate subtrees. For the small trees we build in this explainer, the sweep is instant; for real games, the lib's function caches each position so you pay for each distinct subtree at most once.

A few patterns to discover in the editor:

  • A node whose only option is a leaf has Grundy value 1. Because .
  • A node with two options at values 0 and 1 has value 2. With options at 0, 1, 2, value 3. The pattern matches Nim heaps.
  • A node whose options are {0, 2} (skipping 1) has value 1. Mex ignores the 2; the first hole is at 1.
  • Duplicate children do not matter. Two options both of value 0 still give mex{0} = 1. Mex works on sets, not multisets.

Spend a few minutes on the editor. The goal is not to memorize anything, it is to internalize the mex-over-options rule until it feels obvious. Every result in the rest of this series cashes out to a tree like the ones you are building right now.

Here is the first concrete payoff. A Nim heap of size n is a pile of n stones; from it you can move to any smaller heap, a heap of size 0, 1, 2, …, up to n−1. What are its options? Every smaller heap. What are their Grundy values, assuming we already know the answer for smaller heaps? By induction, the heap of size k has Grundy value k for 0 ≤ k < n. The Grundy value of a Nim heap is its size. The "XOR the heap sizes" recipe you learned in explainer 1 is about to become "XOR the Grundy values," which will work for every impartial game. But we are getting ahead of ourselves, that is the Sprague–Grundy theorem in the next explainer.

Figure 5. Two games, same Grundy value

Grundy values are a strategic invariant: two positions with the same value play identically, even if they have completely different rules and boards. To make that concrete, here are two impartial games side by side. Both have Grundy value 2. One is a Nim heap of 2 stones, the baseline. The other is a subtraction game: you have a pile of 4 chips, and on each turn you must remove exactly 1 or exactly 4 chips. The game ends when you cannot move (pile too small).

The subtraction game is a completely different creature from Nim. Its game tree has a different shape, its moves are different, its stopping rule is different. But as impartial games (as positions in the abstract theory) they are the same. Their Grundy values agree. In the next explainer we will prove this is not a coincidence: the Sprague–Grundy theorem says every impartial game position is equivalent, for all strategic purposes, to a single Nim heap whose size is the Grundy value.

The abstraction we just earned. We no longer need to analyze each impartial game as its own special case. Any two positions with the same Grundy value are strategically interchangeable. The entire zoo of impartial games, Nim, Green Hackenbush, Turning Turtles, Mock Turtles, Wythoff's game, and dozens more we will meet, collapses to one question: what is this position's Grundy value? Takeaways

Three facts carry into the rest of the series:

  • mex is the entire operator. The smallest non-negative integer not in a set. Learnable in ninety seconds; applies to every set.
  • Grundy value = mex of options' Grundy values. Recursive bottom-up. Terminal positions get 0 by fiat (empty set). Every other position is determined by its children.
  • Grundy value is the complete strategic invariant. Same value means same game up to equivalence. Zero means losing. Any nonzero value means winning.

You can now compute the Grundy value of any impartial game position by hand (slowly, but correctly) using nothing more than the recursion we just built. The next explainer promotes this recipe from "a useful number" to a full theorem: the Sprague–Grundy theorem, which proves that every impartial game is equivalent to a single Nim heap. Nim, the first game we ever played in this series, turns out to be the universal model for all of them.
