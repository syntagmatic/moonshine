Surreal Numbers and Simplicity

Part 6 of 10. A blue edge under a red edge is worth half a move. Conway's construction explains where the half comes from, and one rule computes it.

Part 5 found that the Blue-Red stalk with blue under red, the position \{0 \mid 1\}, is worth \tfrac12: two copies of it plus one red edge is a second-player win.

Conway's move was to treat the bracket itself as the definition of a number. Everything on this page follows from that: which numbers exist, how they compare and add, and how to read off the value of any game whose options are numbers.

Numbers from nothing

A number is a pair of sets of numbers already built, written \{L \mid R\}, with one condition: no member of L is \ge any member of R. Order is defined by the same recursion:

x \le y \iff \text{no } x^L \ge y \;\text{ and no }\; y^R \le x.

Here x^L ranges over the Left options of x and y^R over the Right options of y. In game terms, x \le y says that in x - y Left, moving first, has no winning move. The recursion terminates because options are always born earlier than the number they belong to.

On day 0 nothing exists, so both sets are empty: \{\,\mid\,\} = 0. On day 1 we may use 0, giving \{0 \mid\,\} = 1 and \{\,\mid 0\} = -1. The bracket \{0 \mid 0\} breaks the condition. It is still a game: the single green edge from Part 2, written *. It is not a number. Day 2 brings \{\,\mid -1\} = -2, \{-1 \mid 0\} = -\tfrac12, \{0 \mid 1\} = \tfrac12 and \{1 \mid\,\} = 2. From then on each day adds one new number in every gap between the numbers already born, and one beyond each end.

Figure 1. Days 0 to 4, generated by the gap rule above and spaced evenly in order. Each number hangs from the later-born of its two canonical options, the nearest earlier-born numbers on either side. Click or hover a number to see its form \{x^L \mid x^R\} with both options highlighted.

The numbers born on finite days are exactly the dyadic rationals m/2^k. An integer n is born on day |n|; a non-integer x = m/2^k with m odd is born on day \lfloor |x| \rfloor + 1 + k, so \tfrac34 arrives on day 3 and \tfrac52 on day 4. On day \omega the remaining real numbers appear, along with \omega and 1/\omega. Short games never reach that far. Conway found the construction while analyzing Go endgames. Knuth's novella Surreal Numbers (1974) introduced it and gave it its name, two years before Conway's own account in On Numbers and Games (1976).

The simplicity rule

Call a number simpler than another if it is born earlier. The rule that names brackets, and that values every game in the rest of this series whose options are numbers, is this:

Simplicity rule. Let every option of G = \{G^L \mid G^R\} be a number, and let \mathcal L be the largest Left option and \mathcal R the smallest Right option (-\infty or +\infty if a side is empty). If \mathcal L \lt \mathcal R, then G equals the simplest number x with \mathcal L \lt x \lt \mathcal R. If \mathcal L \ge \mathcal R, G is not a number.

There is never a tie for simplest: two numbers born on the same day always have an earlier-born number between them. The simplest number in an open interval is found in two steps. If an integer lies strictly inside, it is the integer of least absolute value (0 if 0 fits). Otherwise the interval lies inside some (m, m+1), and the answer is the dyadic with the smallest denominator in the interval, which is unique; bisecting (m, m+1) finds it.

The proof is short enough to give. Let x be the simplest number in (\mathcal L, \mathcal R), with canonical form \{x^L \mid x^R\}. To show G \le x we need two things. No G^L \ge x: true, since every G^L \le \mathcal L \lt x. No x^R \le G: x^R is born before x and lies above it, so it cannot be in the interval, so x^R \ge \mathcal R. That means G has a Right option \mathcal R \le x^R, which by the definition rules out x^R \le G. The argument for x \le G is the mirror image, and together they give G = x.

Order and addition, unfolded

Addition is defined by the same recursion as a sum of games: in x + y, a player moves in one component and leaves the other alone.

x + y = \{\, x^L + y,\; x + y^L \;\mid\; x^R + y,\; x + y^R \,\}

Negation swaps the sides, -x = \{-x^R \mid -x^L\}. Take \tfrac12 + \tfrac12 with \tfrac12 = \{0 \mid 1\}. The Left options are 0 + \tfrac12 twice and the Right options 1 + \tfrac12 twice, so the sum is \{\tfrac12 \mid \tfrac32\}, and the simplest number between is 1. Nothing here assumed that \tfrac12 means a half; the fraction names are earned by the recursion. The figure runs both definitions on any pair of numbers born by day 3. Sums are never added as fractions: the simplicity rule names each bracket, and ordinary fraction addition appears only at the end as a cross-check.

Values of games

A game's options need not be canonical, and there can be many of them. Only the largest Left option and the smallest Right option matter; the others are dominated, since a player never gains by choosing a worse number.

The last two presets are not numbers. In \{1 \mid 1\} the bounds meet; the game is 1 + *, a point for Left plus one green edge. In \{1 \mid -1\} whoever moves first gains a point: Left moves to 1, Right to -1. Games like that, switches, need the theory of temperature in Part 8.

Back to Hackenbush

Part 5 quoted Berlekamp's shortcut for stalks: edges in the bottom run of one color count \pm 1, and each edge after the first color change counts half as much as the one below it. So blue, red, blue is 1 - \tfrac12 + \tfrac14 = \tfrac34.

The simplicity rule proves the shortcut. In that stalk Left can cut the bottom edge (leaving 0) or the top edge (leaving blue-red, \tfrac12), and Right can cut the middle edge (leaving one blue edge, 1). So it is \{0, \tfrac12 \mid 1\} = \tfrac34. The figure repeats that recursion on any stalk you build and sets it beside the shortcut.
